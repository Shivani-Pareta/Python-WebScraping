# Project 1 : E-Commerce Multi-Page Web Scraping Pipeline (`webscraper.io`)

## Project Overview
This project is the first step of my **Python Web Scraping Journey**, focusing on extracting structured e-commerce data from a test site to understand syntax, loops , libraries and various functions.
This also includes all the codes since the first one and all the learnings from them. 

## Tools and Libraries Used
* **Python 3.12**
* `requests` (HTTP requests)
* `BeautifulSoup4` (HTML parsing)
* `pandas` (Data structuring & CSV export)
